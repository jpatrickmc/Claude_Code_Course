# CLAUDE.md

## Project Identity

It's quiet in the well-lit datacenter at 3AM. This is a single-page static site that recreates that feeling: quiet, orderly, humming with unattended competence. The page should read as a calm, confident piece of infrastructure — nothing loud, nothing that needs a person watching it.

## Stack

Static single-page site. One HTML file with embedded CSS and JavaScript.

- No frameworks
- No npm
- No build tools
- No backend, database, or authentication

## Supporting Documents

- **PRD.md** — the product requirements: vision, personas, feature priorities, and success criteria. Read first, before any other document.
- **content-model.md** — every section of the page, its content fields, and constraints on each field. Read before writing or editing page copy.
- **site-contract.md** — page structure, content inventory, and behaviour spec (navigation, scroll, hover, mobile, transitions). Read before implementing structure or interactivity.
- **design-standard.md** — the full visual specification: colour, typography, spacing, texture, and interaction detail. Read before making any visual or styling decision.
